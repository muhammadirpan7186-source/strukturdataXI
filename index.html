Materi Pembelajaran

Array (Larik)

Array adalah struktur data linear yang menyimpan sekumpulan elemen data yang memiliki tipe yang sama dan disimpan di lokasi memori yang saling berdekatan.

Bayangkan Array seperti sebuah loker di sekolah. Setiap loker memiliki nomor berurutan (disebut Indeks), dan setiap loker hanya bisa menyimpan jenis barang yang sama.

Karakteristik:

  • Ukuran biasanya tetap (statis) setelah dibuat.
  • Akses data sangat cepat karena menggunakan indeks.
  • Indeks biasanya dimulai dari 0 (Zero-based indexing).
Ilustrasi Array (Indeks & Nilai)
0
10
1
25
2
50
3
75

Contoh: Nilai pada indeks ke-2 adalah 50

Tahukah Kamu?

Dalam aplikasi e-commerce, daftar produk yang kamu lihat di halaman utama seringkali disimpan dalam struktur Array untuk memudahkan dan mempercepat sistem menampilkannya di layarmu.

Linked List (Senarai Berantai)

Linked List adalah struktur data dinamis yang terdiri dari simpul-simpul (Node) yang saling terhubung. Lokasi penyimpanannya di memori tidak harus berdekatan (acak).

Setiap Node terdiri dari dua bagian utama:

  • Data: Nilai yang disimpan.
  • Pointer (Next): Penunjuk lokasi Node berikutnya.
Ilustrasi Linked List
A
B
C
NULL

Node terakhir menunjuk ke NULL (kosong).

Info Penting

Kelebihan utama Linked List adalah kemudahannya dalam menambah atau menghapus data di tengah-tengah karena kita tidak perlu menggeser elemen lain, cukup mengubah arah pointer-nya saja. Berbeda dengan Array yang mengharuskan kita menggeser elemen lain.

Stack (Tumpukan)

Stack adalah struktur data linear yang mengikuti prinsip LIFO (Last In First Out). Artinya, data yang terakhir dimasukkan akan menjadi data yang pertama kali dikeluarkan.

Analogi yang paling tepat adalah tumpukan piring kotor. Piring yang terakhir ditaruh di atas tumpukan, akan menjadi piring pertama yang diambil untuk dicuci.

Operasi Utama:

  • Push: Menambahkan elemen ke atas tumpukan.
  • Pop: Menghapus elemen dari atas tumpukan.
Ilustrasi Stack (LIFO)
1 (Pertama)
2
3 (Top)
Push
Pop

Fakta Menarik

Fitur Undo (Ctrl+Z) pada aplikasi seperti Word atau browser (tombol Back) menggunakan struktur data Stack! Tindakan terakhirmu disimpan di tumpukan paling atas, jadi ketika kamu menekan Undo, tindakan itulah yang dibatalkan pertama kali.

Queue (Antrean)

Queue adalah struktur data linear yang bekerja dengan prinsip FIFO (First In First Out). Data yang pertama kali masuk akan menjadi data yang pertama kali keluar.

Sesuai namanya, Queue persis seperti antrean di kasir supermarket atau antrean membeli tiket. Siapa yang datang duluan, dia yang dilayani duluan.

Operasi Utama:

  • Enqueue: Menambahkan elemen ke belakang (Rear/Tail) antrean.
  • Dequeue: Menghapus elemen dari depan (Front/Head) antrean.
Ilustrasi Queue (FIFO)
Dequeue
A
B
C
Enqueue
Front (Depan) Rear (Belakang)

Penerapan

Queue digunakan oleh sistem operasi komputer untuk mengatur antrean pencetakan dokumen (Print Spooler). Dokumen yang kamu perintahkan print pertama kali akan dicetak lebih dulu oleh printer.
